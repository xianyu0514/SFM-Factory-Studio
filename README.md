# SFM Factory Studio（SFM 智造工坊）

一个为 [Super Factory Manager 4 (SFM)](https://github.com/TeamDman/SuperFactoryManager) 打造的
**中文可视化工厂编程附属**：用积木快速搭建自动化，与 SFML 源码同屏双向编辑，
保存到磁盘的始终是标准 SFML——不装本模组的人也能打开你的程序。

- **Minecraft**: 1.21.1
- **模组加载器**: NeoForge 21.1.x
- **前置**: Super Factory Manager 4.34.0（必须安装）
- **当前版本**: 0.7

本模组基于 [Mimosa_LW 的 SFM-GUI](https://github.com/MimosaLW/SuperFactoryManager-GUI) 项目改造
（同为 MPL-2.0 开源），把"节点连线"界面整体替换为更简单直接的**积木式**界面。

---

## 安装

把 `SFM-Factory-Studio-1.21.1-0.7.jar` 放进 `mods` 文件夹。按需求选择安装方式：

| 安装方式 | 编辑器 | NBT 组件筛选 | 服务端 TPS 工具 |
| --- | --- | --- | --- |
| 只装客户端 | ✅ 完整可用（进原版 SFM 服务器也正常） | ❌ 入口自动隐藏 | ❌ |
| 客户端 + 服务端都装 | ✅ | ✅ 解锁（`with #nbt:…` 组件级分流） | ✅ 可选开启 |

使用步骤：放置**工厂管理器**、插入**磁盘**，打开管理器界面，点击左侧新增的
**「智造编辑」** 按钮；从积木库搭建程序，点 **「保存」** 写入磁盘。

## 核心功能

### 积木编辑器

- **触发器卡片自由布局**：无限画布 + 滚轮缩放，卡片拖到任意位置，按中键/右键平移视角；
  布局自动记忆（`config/sfmjimu/layouts.json`，按触发头指纹匹配，改积木不丢位置）
- **积木库**：定时循环（每 N 刻/秒、全局时钟、相位偏移）、红石脉冲、取出/存入/遗忘、
  如果/否则如果/否则（条件支持且/或/非组合）、注释、一键模板（熔炉自动线、满仓分类、
  均衡分配、高频并行）
- **扩展积木**：或者也搬运、另外搬运、限制数量、至少保留、资源特征、排除、
  侧面、槽位、轮流、每个方块分别处理、仅空槽——不用的能力不占主积木
- **框选与批量操作**：框选高亮、整体拖动、复制/粘贴/原地复制/删除、存为自定义模板
- **右键菜单**：卡内右键 = 复制/粘贴/删除；画布右键 = 粘贴/新建
- **撤销/重做**（Ctrl+Z / Ctrl+Y），卡片坐标在撤销后保留

### 画布组织（大程序友好）

- **三分区工作区**：画布拖矩形即可圈出蓝/绿/黄工作区并命名，点击标题聚焦，
  区外卡片蒙纱退后（仍可交互）；分区随布局持久化
- **卡片折叠 / If 折叠**：卡片收成一行摘要，If 收成一行条件，缩略视图不再翻屏
- **LOD 缩略**：缩小到一定级别自动换成摘要行，几百张卡也流畅
- **积木连线**：卡片右上 ◆ 拖到另一张卡建立贝塞尔连线（纯视觉备注，不进 SFML），
  中点 ✕ 可删

### 同屏 SFML 代码双向编辑

- 积木改动实时生成源码；点「代码编辑」后源码与积木同屏，**双向同步**
- 源码区支持语法着色、行号、滚动、剪切/复制/粘贴、撤销/重做、Tab 缩进、
  Ctrl+/ 注释、智能建议（Ctrl+空格）；输入到一半的错误不会清空积木，自动存草稿
- **无损往返**：合法 SFML 的注释、空否则分支、格式在积木↔源码往返中保留；
  测试覆盖 SFM 官方 8 个示例程序、全部语法分支，以及随机生成的 1000 组积木组合
  全部通过 SFM 本体编译器

### 中文诊断

- 保存前经 SFM 本体编译器校验 + 本地体检：缺少标签、冲突侧面、无效槽位、
  恒假条件、排除全覆盖等常见错误在写入磁盘前拦截
- 工具栏「问题」面板：每条问题可**定位**（相机跳转 + 呼吸红框），
  多数带**一键修复**；未绑定标签可一键推送到标签枪

### 资源特征（物品筛选）

- **可视化标签选择器**：先选物品再看它所属的标签（中文名、来源、覆盖范围提示、
  成员预览网格 140 个/页），或全库搜索；拼音输入直接搜中文名
- **且 / 或 / 非**：多条件自由组合，每颗条件药丸可单独删除、整链预览匹配物品
- **NBT 组件筛选**（需双端安装）：从物品可视化选择其非默认组件——附魔（含等级）、
  药水种类、自定义名称、custom_data（子键/多级路径/数值大于小于比较）等，
  编译为 `with #nbt:minecraft/enchantments/sharpness` 形式的伪标签，
  由本模组服务端 Mixin 拦截匹配；SFM 更新导致注入失效时自动退回原版行为不崩服

### JEI 联动（可选）

- 编辑器打开时 JEI 物品管理器常驻右侧，编辑器自动收窄避让
- 所有资源槽都是 JEI 拖放目标：左键拖物品、右键拖流体容器自动识别；
  JEI 书签也能直接拖入
- 未装 JEI 时完全可用，自带目录浏览与输入

### 性能

- 编辑器是纯客户端界面，**不注册任何每刻（tick）事件**，对服务器零开销
- 增量布局引擎：编辑只重排内容变化的卡（内容哈希差分），拖动走缓存平移，
  渲染只画视野内的卡片；命中检测对象池化；NBT 选择器全注册表缓存一次构建
- 大程序实测路径：卡片折叠 + LOD + 分区聚焦，几百张卡仍可流畅编辑

### 服务端 TPS 工具（可选，默认全关）

模组列表 → 选中本模组 → **配置**（全中文界面，或编辑 `config/sfmjimu-common.toml`）：

- **空转退避**：连续空转的管理器把定时检测间隔逐级拉长，搬运成功立即恢复
  （每秒平均搬运量不变；代价是空闲工厂首件检测最多多等几个周期）
- **每刻全局预算**：所有管理器单刻总耗时封顶，超出者本轮顺延（会损失该轮吞吐，
  只适合 TPS 垂死的服务器）
- **默认全部关闭 = 与原版 SFM 行为完全一致**（吞吐与首件延迟都不变），
  修改保存后即时生效，无需重启

## 关于速率上限

SFM 服务器配置中 `timerTriggerMinimumIntervalInTicks` 默认 20（每触发器最快 20 刻一次），
最小可设 1。设为 1 后触发器每刻运行，配合多触发器并行吞吐可任意扩展。
编辑器会读取当前服务器下限并在填写时自动收敛；导入的旧程序若低于下限会明确提示。

## 已知限制

- 积木连线是纯视觉备注，不参与 SFML 语义
- NBT 组件匹配覆盖物品与流体；**Mekanism 化学品不支持**（ChemicalStack 不走原版组件系统），
  潜影盒内容/烟花配置/成书等复杂嵌套组件仅支持存在性匹配
- 仅在客户端安装时，NBT 筛选入口隐藏（原版 SFM 服务端物理上无法分流）

## 构建

需要 JDK 21：

```bash
./gradlew build        # 产物在 build/libs/
./gradlew test         # 117 项单元测试（模型/序列化/布局/诊断/NBT 匹配）
```

正式发行 JAR 内置 [PinIn](https://github.com/Towdium/PinIn)（MIT）拼音搜索库；`-slim.jar` 仅供开发调试。
构建前需将 SFM 4.34.0 的 jar 放到 `libs/sfm-4.34.0.jar`（路径见 `gradle.properties`，不会进入本仓库）。

> 注：本机 Gradle 需走 IPv6 访问 maven.neoforged.net 时，可用
> `JAVA_TOOL_OPTIONS="-Djava.net.preferIPv6Addresses=true" ./gradlew build`。
