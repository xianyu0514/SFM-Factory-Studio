# 默认代码视图与快速收起（0.9.1 预览）

- 首次打开：空间足够时默认积木 60%、代码 40%，不自动聚焦代码输入。
- F6 / 工具栏“代码、收起” / 代码区顶部“收起”：切换代码区展开状态。
- F7 / 专注按钮：切换专注代码与分屏；小窗口从专注视图返回积木。
- 分屏可拖动；代码区可用宽度低于 280 或上下工作区高度低于 260 个编辑器逻辑像素时，默认保留积木。主动展开代码时使用完整代码视图。
- 自动收起只影响当前布局，不修改已保存的展开意愿；放大窗口恢复分屏和比例。
- 按管理器记住展开状态、专注视图、换行与比例；兼容 0.9.0 的三字段布局记录，缺失的展开字段按默认展开处理。
- 未完成或无法导入的源码优先显示，避免隐藏玩家需要修复的内容。
- 收起不删除草稿、代码、选区和撤销历史，取消当前鼠标捕获，避免隐藏后残留拖动。

## 验证

新增 CodeViewPreferencesTest 验证默认比例、JSON 往返、旧记录迁移、无效值和小窗口临时回退。原有滚动条、分屏、替换与编译测试继续运行。
