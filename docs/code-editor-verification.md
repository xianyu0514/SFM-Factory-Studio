# 代码编辑器验收

本轮两版本同步：缩放裁剪、行号与正文独立裁剪、双向拖动滚动条、分屏调整、专注视图、显示换行、查找与行号跳转、输入撤销分组、光标与历史保留。

## 操作

- F7：切换代码专注 / 分屏；代码未打开时直接进入专注视图。
- Alt+Z：切换显示换行；SFML 内容与真实行号保持不变。
- Ctrl+F：区分大小写的字面查找；F3 / Shift+F3 循环定位下一处 / 上一处。
- Ctrl+G：跳到真实代码行；超过总行数时定位末行。
- Ctrl+Space：请求补全；采用 SFM 配置的接受补全键。
- Shift+滚轮：水平滚动；底部和右侧滚动条可以拖动。
- 编辑菜单：查找、跳行、撤销、重做、保存、返回积木。
- 代码区顶部边界可上下拖动。窗口过小时自动使用代码视图。

5. 测试多行粘贴、缩进、注释、连续输入分组撤销、重做、保存后重开与草稿恢复。

## 第二轮交互修复

- 父界面先设置代码焦点，再处理按下，避免其焦点交接清掉滚动条拖动状态。
- 拖动与释放优先交给捕获指针的代码区，鼠标移出边界仍可完成拖动。
- 代码区滚轮优先于积木栏处理，避免专注视图的隐藏积木栏吞掉滚轮。
- 滚动条命中宽度扩大到 10；按住滑块保留抓取位置，点击轨道翻页，小幅滚轮输入累计。
- 顶部从 44 缩为 24，状态合并到底部行列栏，完整信息悬停可见。

游戏内补充验收：重复按住同一个滑块拖动；拖出边界后释放；专注视图左半区滚轮；触控板连续小幅滚动；上下/左右轨道点击翻页；不同 GUI 缩放下检查底栏和代码可视范围。

## 第三轮功能

- 滚动条仅在溢出时出现，消失后释放正文空间；自动换行时不显示横向滚动条。
- 点击底栏错误提示或“编辑 → 代码错误”查看错误，选择带编译器行列位置的错误后定位并高亮真实代码行。没有位置的错误保留说明，不猜测位置。代码修改后旧定位失效。
- Ctrl+H 或“编辑 → 替换”：输入查找内容和替换内容，选择替换下一处或全部替换。全部替换显示数量，留空替换文本表示删除；字面匹配、区分大小写，无正则替换。修改后 Ctrl+Z 可一次撤销。
- 替换超出 SFML 长度限制时保留原文，不截断。

补充验收：空文档无空滚动条；长行与长文档分别触发两种滚动条；调整宽度后滚动条正确增减；开启换行后错误定位仍对应真实行；修改后旧错误不再跳转；替换全部后撤销恢复原文；取消替换不修改内容。
