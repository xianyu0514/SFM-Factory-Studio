## 一、角落控制（v4 修正版）

### 触发器卡
- **移除头部右上 ✕**（用户确认无用；删卡入口收敛到底部 − 一个）；
  右上只留 ◀ ▶ 排序。
- **底部 ＋ 不变**：整卡深拷贝（内部积木完全一样），排在正下方——高频并行
  卡的复制入口。
- **底部 − 不变**：删除当前这张卡（即把 ＋ 复制出来的多余副本删掉一个）。

### 判断积木（If）
- **行首左上角 ✕**：删除整个 If（含全部分支与 else 体，pushUndo 可撤销）；
  现有的分支行右端 ✕ 语义不变（删当前分支；分支删空则整块消失）。

### 折叠（不占用 − / ＋）
- 卡头左侧加 ▾/▸ 小角标：折叠后剩标题条 + 摘要"3 取出 · 2 放入 · 1 判断"；
- If 条件行左侧同样 ▾/▸：折叠成一行条件摘要；
- 折叠态按 triggerKey/结构指纹存 layouts.json，撤销/代码同步不丢。

### 通用规则
- 删除/复制走 pushUndo；折叠不进 SFML；IO 积木"＋扩展/−收起"语义不动。

## 二、卡片紧贴对齐（并排看着是一体）

### 行为
拖动卡片（单卡或整组）松手前的实时吸附：
- **横向贴边**：被拖卡左缘接近其他卡右缘（阈值 16 内容 px）→ 吸附
  `x = 对方.x + 卡宽`（完全贴平）且 `y = 对方.y`（顶边对齐）；右缘同理。
- **纵向贴边**：接近其他卡正下方 → `y = 对方.y + 对方.高 + CARD_GAP`
  （保持现有节奏间距，不零距离——卡片有投影，零距会糊）。
- 吸附瞬间在贴合边显示一条高亮指示线（松手消失）；吸附结果仍落在 8px 网格。
- **成组拖动**：整组按被抓卡吸附，其余卡保持相对队形（现有组拖逻辑天然支持）。
- 与避让的关系：贴边 = 用户主动摆放，视为 keepPos 卡（现有机制），松手后
  避让不会把刚贴好的卡推开。

### 观感"一体"
- 贴合的两张卡接触边的边框减淡（soft border），视觉上连成一个宽块；
- 折叠（第一节）+ 贴边组合：一排折叠的并行卡 = 一条整齐的"队列条"，
  这就是"高频并行看着一体不乱"的最终形态。
- 可选打磨（便宜就做）：贴合簇外圈画一圈极淡的整体轮廓。

### 不做
- 不做磁吸强度设置/开关 UI（阈值 16px 足够克制，不影响自由摆放）；
- 不做积木行级别的贴边（行在卡内，本来就是对齐的）。

## 三、纯客户端化（静默降级 + 零影响保证）

### 改造（约半天）
1. `SFMGuiNetwork`：`event.registrar("1").optional()`（API 已核实存在）。
2. 发送守卫：`serverSupportedLabels()`（实现时 javap 确认协商数据查询入口，
   兜底 try/catch 一次性探测后置标志），包住 RequestLabels/PullLabels 两处发送。
3. 降级**全部静默**：未绑定标签提醒自动消失（空数据禁用检查，不会误报）、
   标签弹窗隐藏绑定数徽章与服务器标签区、问题面板隐藏"推送标签枪"按钮。
   **不显示任何"服务器未安装"提示。**
4. mods.toml 不动。

### 零影响保证（重要功能逐项为何不受影响）
| 主要功能 | 为什么不受纯客户端化影响 |
|----------|--------------------------|
| 打开编辑器/积木编辑 | 纯客户端 UI + 本地模型 |
| **保存到管理器** | 走 SFM 自己的包；SFM 必然在服务端（没有 SFM 就没有管理器方块） |
| 代码双向同步/撤销/草稿/模板/布局 | 全部本地文件与本地逻辑 |
| 诊断（结构错误、类别核对、恒假条件…） | oracle 用客户端注册表；仅"未绑定标签"一条降级消失 |
| JEI 拖放/物品浏览 | 纯客户端 + JEI |
| 工作区/连线/折叠/搜索（本计划新功能） | 全部客户端数据，设计上不依赖网络 |

### 验证矩阵（必须全过才交付）
1. 专用服只装 SFM + 客户端装本模组：连入正常、编辑器全功能可用、保存成功、
   保存后重开内容一致、诊断正常、无任何报错与提示；
2. 双端都装：全功能回归（与现版本行为逐项一致）；
3. 单人（含开放局域网）：全功能回归；
4. 全部 91+ 项测试绿。

## 四、高效积木操作最终清单（鼠标优先版）

### 做
| 功能 | 形态（全部鼠标可达） |
|------|---------------------|
| Redo | 工具栏「撤销」旁加「↩ 重做」按钮（Ctrl+Y 赠品）；undo 压入重做栈，编辑清空重做栈 |
| 统一搜索 + 批量替换 | 工具栏加「🔍」按钮（Ctrl+F 赠品）：弹搜索浮层，类型 Tab（标签/资源/槽位/文字），拼音匹配；结果点击定位；标签/资源支持多选「全部替换」（一次 undo） |
| 下一问题 | 问题面板头部「上一个/下一个」按钮（F8 赠品），按 错误→提醒 循环定位 |
| 折叠 | 卡折叠 + If 折叠（第一节的 − 按钮），含头部摘要 |
| IO 互转 | Input/Output 扩展菜单加"转为放入/转为取出"，保留全部限制/排除/侧面/槽位 |
| Shift+点击行加选 | 现有多选体系的小补全（触发器头已支持） |
| 模板插入标签注入 | 插入"我的模板"检测到标签 → 弹层一次填好（替代参数化模板） |
| 删除确认（打磨） | ✕ 删除整卡/整 If 属大动作：首次显示 1 行确认浮层"已删除，Ctrl+Z 可撤销"（状态栏提示已有，不弹对话框） |

### 砍（含本轮新砍）
| 功能 | 理由 |
|------|------|
| **Ctrl+K 命令面板**（本轮砍） | 用户拍板鼠标为主；其核心价值是键盘插入，鼠标用户从左侧调色板点/拖已是一步 |
| 完整键盘操作 | 鼠标直接操作式编辑器，键盘全覆盖成本极高收益极低 |
| IF/ELSE 专用连线 | 同卡嵌套相邻，零信息量；通用连线已覆盖 |
| 参数化模板（显式定义） | 用"插入时标签注入"拿 80% 收益 |
| 通用批量修改面板 / 槽位批量替换 | 高频场景已由批量替换+IO 互转覆盖；槽位语义不适合全局替换 |
| "复制并修改输入/输出"独立功能 | IO 互转替代 |

## 五、沿用 v2 的设计（要点复述）

- **LOD**：zoom < 0.55 只画卡标题条+摘要+角标+选中框，不画正文行与行命中框；
  只减绘制不减布局。与折叠互补（LOD=临时缩小，折叠=永久收起）。
- **三色工作区 + 聚焦**：拖矩形创建 → 命名+三色（固定蓝/绿/黄柔和色）；
  大字名称 1.5×；标题条拖动/缩放/✕/双击改名；点区名聚焦（其他区卡片淡出
  alpha 0.15 不可交互）。存 layouts.json（zones 字段）。
- **判定积木连线（通用）**：纯视觉备注+导航，不进 SFML；If 行/卡头两侧端口
  圆点，拖贝塞尔连接；点线中点跳转两端；持久化走触发器指纹+块路径迁移。
- **性能尾包**：Hit 池化去 lambda（消灭每帧数千分配）、oracle 异步预热（消首开
  卡顿）、font.width 双算消除、极低 zoom 点阵抽稀。
