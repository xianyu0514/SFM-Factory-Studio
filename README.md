# SFM 智造工坊 (SFM Factory Studio)

一个为 [Super Factory Manager 4 (SFM)](https://github.com/TeamDman/SuperFactoryManager) 打造的
**中文可视化工厂编程附属**。用积木快速搭建自动化，也能与 SFML 源码同屏精确编辑。

- **Minecraft**: 1.21.1
- **模组加载器**: NeoForge 21.1.206
- **前置**: Super Factory Manager 4.34.0（必须安装）

本模组基于 [Mimosa_LW 的 SFM-GUI](https://github.com/MimosaLW/SuperFactoryManager-GUI) 项目改造
（同为 MPL-2.0 开源），把"节点连线"界面整体替换为更简单直接的**积木式**界面。

---

## 安装 / 使用

1. 安装 NeoForge 1.21.1 + Super Factory Manager 4.34.0
2. 把 `SFM-Factory-Studio-1.21.1-0.1.0.jar` 放进 `mods` 文件夹（正式版已内置拼音搜索）
3. 放置**工厂管理器**、插入**磁盘**，打开管理器界面
4. 点击左侧新增的 **「智造编辑」** 按钮
5. 从左侧积木库点击积木搭建程序，点 **「保存」** 写入磁盘

积木程序会实时生成标准 SFML 文本（点「代码编辑」可与积木同屏修改），磁盘上存的始终是
普通 SFML。点顶部「代码编辑」后，积木与源码会在同一屏双向同步，无需再切回原版文本编辑器。

## 界面说明（v0.3 毛玻璃窗口版）

- **窗口化布局**：编辑器以居中窗口呈现（约 94% 屏宽），面板为约 85% 不透明度的玻璃质感，可直接透出游戏世界（不触发原版菜单模糊，兼容各类整合包）
- **确定性布局引擎**：先测量后绘制，积木永不重叠/漂移（修复旧版错位重影）
- **无限画布 + 滚轮缩放**：触发器卡片可以放到原点左侧或上方；在画布任何位置
  （包括积木上）按住中键或右键即可平移视角，没有左/上边界。迷路时点工具栏「适配」重新居中
- **任意位置拖动积木**：按住积木条任意空白处即可拖动（字段仍点击编辑）
- **框选与批量操作**：空白处左键拖动框选（实时高亮），或 **Ctrl+左键** 在任意位置（包括积木上）起框；松手后鼠标处弹出悬浮工具栏（复制 / 存为模板 / 删除 / 取消）；选中可整体拖动、Ctrl+C/V、**Ctrl+D 原地快速复制**、Del；自定义模板存于 config/sfmjimu/templates.json

- **积木库（左侧）**：
  - 触发器：`循环执行`（每 N 刻/秒，支持全局时钟与偏移）、`红石脉冲`
  - 物流：`提取`（INPUT）、`存入`（OUTPUT）、`遗忘`（FORGET）
  - 逻辑：`如果 … 那么`（IF/ELSE IF/ELSE，条件支持 且/或/非 组合）
  - 说明：`注释`（用日常中文写程序内备注）；旧版本残留内容只读显示，不能再创建不可校验的代码块
  - 一键模板：`熔炉自动线`、`满仓分类`、`均衡分配`、`高频并行`（自动生成 3 个并行触发器）
- **画布（中间）**：淡蓝灰底 + 点阵网格的白色圆角卡片
  - **触发器卡片可自由拖放**：按住卡片标题拖到任意位置，多卡片并排布局
  - **卡片位置自动记忆**：布局存于 `config/sfmjimu/layouts.json`（按管理器分键、按触发头指纹匹配，改积木不丢位置）；撤销（Ctrl+Z）后位置照常保留
  - 每张“什么时候运行”卡片右下角都有 **− / ＋**：`＋` 深度复制整张卡，触发条件、
    判断、输入输出、嵌套内容和所有扩展积木全部保持一致，副本自动排列在原卡正下方；
    `−` 删除整张运行卡
  - 积木块可拖拽排序，松手自动吸附到最近的插入位置（跨卡片移动）
  - 判断分支按实际内容紧凑排布；“否则如果”和“否则”紧跟上一分支，不会随卡片坐标产生额外空白
  - 积木库支持**拖拽到画布**或点击放入选中容器
  - 点积木上的圆角字段直接编辑：标签多选（拼音搜索）、资源图标选择器、
    数字、比较方式、侧面、槽位、轮流、保留、资源特征、每个方块分别处理等
  - INPUT / OUTPUT 主积木只保留最常用的“标签 + 资源类别 + 资源槽”；点击
    **「＋ 扩展积木」**才会添加“或者也搬运、另外搬运、最多搬运、至少留下、
    资源特征、排除、侧面、槽位、轮流、每个方块分别处理、仅空槽”等独立子积木。
    这些能力不会伪装成主积木自带的“规则”
  - 卡片标题栏 `◀ ▶` 调整触发器顺序，`✕` 删除
- **保存**：右上角绿色 **保存** 键或 **Ctrl+S**；修改后显示红色 "未保存" 提示；
  保存前经 SFM 本体编译器校验 + 本地体检；没有取出就存入、空任务、缺少标签、
  冲突侧面、无效槽位、无效资源特征等不会写入磁盘
- **同屏代码编辑**：源码区支持语法着色、行号、横纵滚动、选择、剪切/复制/粘贴、
  撤销/重做、Tab 缩进、Shift+Tab 反缩进、Ctrl+/ 注释、SFM 智能建议与 Ctrl+空格检查；
  停止输入后才同步积木，输入到一半的错误不会清空已有积木，且会原样进入自动恢复草稿
- **资源特征预览**：内置 14×10 网格，每页直接显示 140 个成员并支持翻页；只绘制当前页，
  不依赖 JEI 也能快速确认标签实际包含哪些物品
- **性能**：编辑器是纯客户端界面，不注册任何每刻（tick）事件；资源目录只构建一次并按类别索引；
  自定义模板只在首次使用或保存后更新，不再每帧读取磁盘；画布只绘制视野内的卡片、语句和判断分支；
  同屏代码编辑只绘制可见行并延迟校验；积木高度、主体位置、资源图标与语法高亮均按需缓存；拖动期间跳过重叠计算，
  松手后再执行完整自动避让
## JEI 原版联动（专属适配）

- 编辑器打开时，**JEI 原版物品管理器（含标签页）常驻显示在编辑器右侧**——编辑器窗口自动收窄避让，互不遮挡
- 资源由两个独立字段组成：先选**类别**，再在旁边的**资源槽**选择具体资源；
  资源槽留空表示该类别的全部资源。只有物品允许省略类别，生成 `stone` 或 `*`；
  流体、化学品、气体、浆液、颜料、红石、灌注物、FE 能量始终生成 `fluid::water`、
  `chemical::` 等带类别的合法语法
- 所有**资源槽位**都是 JEI 拖放目标：从 JEI 列表**左键拖物品**=填入物品 ID；**右键拖流体容器**（水桶等）=自动识别流体；拖流体/化学品条目会先检查所选类别，不匹配时提示先切换类别，避免悄悄改写语义
- **书签也能拖**：把常用物品按 `A` 加入 JEI 书签（编辑器左侧的书签栏），直接从书签拖进资源槽，常用资源一步到位
- 点击类别字段可选择全部 SFM 资源类别；点击资源槽可浏览当前类别、输入 ID 或清空为“全部”
- **未装 JEI 时**：自带目录只显示已经选择的类别，不再把“资源类别”和“具体资源”混在同一页

## 关于速率上限

SFM 服务器配置（`world/serverconfig/sfm-server.toml` 或对应 server config）中
`timerTriggerMinimumIntervalInTicks` 默认为 **20**（每触发器最快 20 刻一次），**最小可设 1**。
设为 1 后触发器即每刻运行；配合多触发器并行，吞吐可任意扩展——百科所称"无上限"即源于此。
编辑器会读取当前服务器下限，并在填写时自动收敛到可用值；导入的旧程序若低于当前下限，
会明确提示且不会写入坏程序。

## 构建

需要 JDK 21：

```bash
./gradlew build        # 产物在 build/libs/
./gradlew test         # 运行积木 ↔ SFML 往返转换单元测试
```

正式发行 JAR 内置 [PinIn](https://github.com/Towdium/PinIn)（MIT）拼音搜索库；`-slim.jar` 仅供开发调试。

> 注：本机 Gradle 需走 IPv6 访问 maven.neoforged.net 时，可用
> `JAVA_TOOL_OPTIONS="-Djava.net.preferIPv6Addresses=true" ./gradlew build`。

## 覆盖范围

积木模型覆盖当前 SFML 完整语法：触发器、输入/输出、多个资源扩展组、数量/保留、
资源特征的且/或/非、侧面/槽位/轮流、每个方块分别处理、排除、
IF/ELSE IF/ELSE、常量/红石/库存条件以及任意且/或/非组合。

合法 SFML 的执行逻辑可稳定往返为结构化积木，不再靠可编辑的「原样代码」兜底。
源码测试会直接检查 SFM 仓库的 8 个官方示例、项目内官方模板、全部语法分支，
并随机生成 1000 组积木组合交给 SFM 本体编译器验证。SFML 注释不影响执行，源码与积木往返时会保留；
积木中新写的中文注释也会正常生成到代码中。
